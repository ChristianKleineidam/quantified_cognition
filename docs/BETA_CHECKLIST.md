# Public desktop beta acceptance

Target: Quantified Cognition 0.23.0 with Oura and optional research participation
available at the same launch. Google Health remains disabled. Earlier detailed
walkthroughs and limits are in [DESKTOP_BETA.md](DESKTOP_BETA.md).

## Completed engineering and rehearsals

- Recall and formation, including short/long metrics, completeness, uncertainty
  and insufficient-data labels; full history, phase comparisons and return visits.
- Statistical simulations, native Anki/Qt checks and private-history performance
  checks; background CSV retries, queue completion and close-after-final-answer.
- Disposable Windows and Linux installs/upgrades, encrypted credential/cache
  checks and live AnkiWeb synthetic review sync between dedicated test profiles.
- Oura authorization, paginated history, refresh rotation, partial grants,
  sleep/stages/naps/steps/workouts and incremental reconciliation. Application
  approval and removal of the ten-user cap are recorded.
- Explicit enrollment, frozen/saveable information and health-data consent linked
  to the participant ID; original before-results preference audit preserved.
- Client-encrypted daily and per-review uploads, immutable retry receipts,
  off-server decryption and a known Brier-score reconstruction.
- Hosted scheduled revocation while the client was closed, guarded process
  shutdown, active-data deletion and removal/confirmation of inventoried copies.
  See [focused evidence](research-e2e-2026-11-08.json).
- Independent monitoring/alerts, bounded quotas, encrypted recovery, external
  deletion ledger, annual retention holds and native restore/withdrawal rehearsals.
- The operator's restricted analysis workspace, protected off-server key and
  guarded scientific runtime are configured. No collaborator is authorized.

## Final release acceptance

Record the exact outcomes in the release provenance and deployment attestation:

1. Final documents and protocol match the plugin, server and public pages;
   launch wording contains no obsolete enrollment-closed claim. The internal
   [data-protection assessment](DATA_PROTECTION_ASSESSMENT.md) records scope,
   proportionality, risks, controls and continuing review.
2. Source/history/package privacy checks pass; the final committed revision
   passes Silentworker, including native PostgreSQL. Build from its new tag.
3. Install that exact archive in a clean synthetic profile and check the concise
   sharing disclosure, eligibility, explicit consent and personal-use alternative.
4. Apply the tested monitor/document migrations and deploy the matching operator
   agents. Review initial quotas; preserve deletion capacity and the kill switch.
5. Activate only the matching current protocol, Oura research permission and
   server upload flag. Verify configured open-state monitoring, public enrollment
   information, anonymous denial, closed Google routes and emergency closure.
6. Publish the reviewed website, source repository and checksum/provenance-bearing
   release; submit the same package and saved description to AnkiWeb when the
   publishing account is eligible.

A separate research release is not required. User feedback, broader load work
and macOS issue reports continue after launch. macOS remains unverified; an
accessibility audit is excluded at the operator's request. Invitations to other
users are not sent automatically.
